# Seismic AI Interpretation

Дипломный проект: «Разработка интеллектуальной системы автоматизированной интерпретации сейсморазведочных данных с использованием нейронных сетей».

## Участники
- Жақсылық Аруана — архитектура системы, backend, интеграция, тестирование и документация.
- Рафикова Шұғыла — нейросетевой модуль, подготовка данных и экспериментальная оценка.

## Текущий этап
Подготовка прототипа программной системы и материалов к апробационному периоду.
