# Data

Исходные большие наборы данных не следует загружать в Git-репозиторий без проверки лицензии и размера.

Здесь должны храниться:
- описание используемого dataset;
- ссылка на источник;
- формат данных;
- инструкция по подготовке данных.

Локальные данные рекомендуется хранить в `data/raw/` и исключить из Git через `.gitignore`.
