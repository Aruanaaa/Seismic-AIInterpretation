# Архитектура системы

## Общая схема

```text
Сейсморазведочные данные
        ↓
Data Loader
        ↓
Preprocessing
        ↓
ML Model
        ↓
Postprocessing
        ↓
Backend API
        ↓
Web Interface
        ↓
Визуализация результата
```

## Компоненты

### Data Loader
Отвечает за загрузку входных данных и первичную проверку формата.

### Preprocessing
Подготавливает данные для подачи в ML-модель. Конкретные операции будут определены после выбора dataset и архитектуры модели.

### ML Model
Нейросетевой модуль интерпретации сейсмических данных. Разрабатывается отдельно и подключается через согласованный программный интерфейс.

### Backend API
Предоставляет API для загрузки данных, запуска обработки и получения результатов.

### Frontend
Предоставляет пользовательский интерфейс для загрузки данных и просмотра результатов.

## Интеграционный контракт

На текущем этапе backend использует mock-реализацию вместо ML-модели. Это позволяет независимо разрабатывать программную оболочку и позднее заменить mock на реальную модель без изменения внешнего API.
