# Требования к прототипу

## Функциональные требования

1. Система должна принимать входные данные в согласованном формате.
2. Система должна проверять корректность загружаемого файла.
3. Система должна выполнять preprocessing.
4. Система должна запускать ML-модуль.
5. Система должна возвращать результат интерпретации.
6. Система должна предоставлять результат пользователю через API и, позднее, web-интерфейс.

## Нефункциональные требования

- модульная архитектура;
- разделение backend и ML-компонента;
- воспроизводимый запуск;
- документированные интерфейсы;
- возможность автоматического тестирования;
- журналирование ошибок.

## Ограничения текущего этапа

На момент апробации dataset и финальная ML-архитектура ещё уточняются. Поэтому программная оболочка использует временный mock-модуль для демонстрации интеграционного сценария.
